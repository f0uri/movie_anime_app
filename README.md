# لُمعة — منصة أفلام وأنمي عربية

واجهة بث عربية حديثة ومتجاوبة مبنية بـ React وVite، تعرض تجربة كاملة لاكتشاف الأفلام والأنمي ومشاهدتها داخل التطبيق.

## المزايا

- واجهة RTL عربية كاملة بتصميم سينمائي.
- صفحة رئيسية، أفلام، أنمي، أحدث الإضافات، وقائمتي.
- بحث سريع بالاسم والتصنيف والسنة (`Ctrl/⌘ + K`).
- فلاتر حسب النوع والتصنيف.
- متابعة المشاهدة مع مؤشرات تقدّم.
- حفظ المفضلة محليًا عبر `localStorage`.
- نافذة تفاصيل لكل عمل ومشغّل فيديو داخل التطبيق.
- تصميم متجاوب للحاسوب، الجهاز اللوحي، والهاتف.
- صور أصلية مولّدة خصيصًا للنموذج بدون شعارات خارجية.

## التشغيل

```bash
npm install
npm run dev
```

ثم افتح `http://localhost:5173`.

## الاختبارات

```bash
npm run lint
npm run build
```

## ملاحظة المحتوى

المحتوى والعناوين في هذه النسخة تجريبية، ويستخدم المشغّل فيديو اختبار مفتوحًا. عند تحويل المشروع إلى منتج فعلي يجب ربطه بواجهة API وقاعدة بيانات ومزوّد بث مرخّص، مع نظام مصادقة وحماية روابط الفيديو وحقوق العرض.
