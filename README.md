# لومين · Lumen

مساعد محادثة عربي بواجهة **زجاجية (Glassmorphism)** وحركات ناعمة بأسلوب **iOS**، يقرأ ويحلّل **عشرات صيغ الملفات**.

## المزايا

**الواجهة**
- زجاج حقيقي: `backdrop-filter` مع حواف شعرية وظلال داخلية، فوق خلفية شفقية متحركة (aurora) وطبقة حبيبات.
- حركات زنبركية بأسلوب iOS: ضغط الأزرار، شريط جانبي منزلق، ورقة إعدادات سفلية على الجوال.
- RTL كامل، وضع داكن/فاتح، تحكّم بحجم الخط، ووضع «تقليل الحركة».
- دعم `safe-area` لشاشات الآيفون، وتصميم متجاوب من الجوال إلى سطح المكتب.

**الملفات**
| الفئة | الصيغ |
|---|---|
| مستندات | PDF · DOCX · TXT · MD · RTF |
| جداول وبيانات | XLSX · XLS · ODS · CSV · TSV · JSON · JSONL |
| أرشيفات | ZIP (يقرأ محتوياتها ويستخرج نصوصها) |
| شيفرة | JS/TS/JSX/TSX · PY · GO · RS · JAVA · C/C++/C# · PHP · RB · SWIFT · KT · SQL · HTML/CSS · YAML · وأكثر من 60 امتدادًا |
| وسائط | PNG · JPG · WEBP · GIF · SVG · AVIF · MP3 · WAV · MP4 · MOV … |
| ترجمات | SRT · VTT · ASS |

الرفع بالسحب والإفلات، أو باللصق من الحافظة (⌘V)، أو بزر الإرفاق — حتى 25 ملفًا و200 ميغابايت للملف.

**المحرك**
- **محلي افتراضيًا (بدون أي مفتاح):** تلخيص استخراجي (TextRank مبسّط)، إحصاءات نصية، كلمات مفتاحية، بحث عبر كل الملفات بأرقام الأسطر، ومراجعة شيفرة (أسرار مكشوفة، TODO، تعقيد، نسبة تعليقات).
- **مزوّدات اختيارية:** OpenAI · Anthropic · Groq · OpenRouter · أي خادم متوافق مع OpenAI — مع بثّ حيّ للردود ودعم الرؤية للصور. المفتاح يُحفظ في متصفحك فقط، وعند فشل الاتصال يتحوّل التطبيق تلقائيًا إلى المحرك المحلي.

## 📱 تطبيق أندرويد (APK)

التطبيق أصبح **مستقلًا بالكامل**: لا يحتاج أي خادم. كل شيء — قراءة PDF وWord وExcel وZIP، التلخيص، الإحصاء، البحث، ومراجعة الشيفرة — يعمل داخل الهاتف ودون إنترنت. الخطوط مضمَّنة محليًا أيضًا.

### الحصول على رابط التنزيل المباشر

بيئة الوكيل محجوبة عن خوادم Google (Android SDK) ولا يملك حسابه صلاحية `workflows`، لذا البناء يتم على GitHub Actions. شغّل مرة واحدة:

```bash
bash ci/enable-apk-build.sh
```

خلال ~5 دقائق سيصبح الرابط المباشر جاهزًا هنا:

**https://github.com/f0uri/movie_anime_app/releases/latest**

يبني خط الإنتاج نسختين: `lumen-release.apk` (موقّعة، للتثبيت) و`lumen-debug.apk`.

### البناء محليًا

يتطلب JDK 21 وAndroid SDK:

```bash
npm install
npm run apk:debug     # android/app/build/outputs/apk/debug/app-debug.apk
npm run apk:release   # نسخة موقّعة
```

### مواصفات التطبيق

| البند | القيمة |
|---|---|
| المعرّف | `ai.arena.lumen` |
| الاسم | لومين |
| الحد الأدنى | أندرويد 7.0 (API 24) |
| الهدف | API 36 |
| الحجم التقريبي | ~6 ميغابايت |
| الأذونات | الإنترنت (للمزوّد فقط) + قراءة الوسائط |

يدعم أيضًا **المشاركة**: افتح أي ملف في هاتفك ← «مشاركة» ← لومين.

## التشغيل (الويب)

```bash
npm install
npm run dev      # http://localhost:5173
npm run build    # نسخة إنتاج ثابتة في dist/
```

## أوامر المحرك المحلي

| الأمر | الوظيفة |
|---|---|
| `لخّص` | خلاصة استخراجية للملفات المرفقة |
| `إحصاء` | كلمات، أسطر، جمل، زمن القراءة، اللغة |
| `كلمات مفتاحية` | أهم المصطلحات مع رسم تكراري |
| `فحص الكود` | مراجعة أمنية وأسلوبية للشيفرة |
| `ابحث: كلمة` | بحث في كل الملفات مع أرقام الأسطر |
| `مساعدة` | قائمة الأوامر |

## اختصارات

`⌘K` محادثة جديدة · `⌘/` الإعدادات · `Enter` إرسال · `Shift+Enter` سطر جديد

## البنية

```
src/
  App.tsx           الصدفة، الدردشة، البثّ، السحب والإفلات
  components/       Markdown · FileChip · Sidebar · Settings
  lib/extract.ts    استخراج المحتوى من كل الصيغ (داخل المتصفح)
  lib/localEngine.ts التحليل المحلي (تلخيص، إحصاء، بحث، مراجعة كود)
  lib/engine.ts     الاتصال بالمزوّدين + البثّ + التحويل التلقائي
  lib/native.ts     تكامل أندرويد (شريط الحالة، زر الرجوع)
  lib/store.ts      الحالة والتخزين المحلي
android/            مشروع Capacitor لأندرويد
ci/build-apk.yml    خط بناء APK ونشره
```
